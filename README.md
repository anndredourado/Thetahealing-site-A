# Anndré Dourado — ThetaHealing® DNA Básico

Site estático completo, com a versão atual do vídeo, máscara de som e links de inscrição e WhatsApp.

## GitHub e Netlify

1. Extraia este ZIP.
2. Envie TODO o conteúdo extraído para a raiz do repositório no GitHub. Preserve a pasta assets. Não envie apenas o ZIP.
3. Na Netlify, importe esse repositório.
4. Deixe o comando de build vazio. Diretório de publicação: `.` (raiz). O netlify.toml já configura esse diretório.
5. Publique e teste os botões no endereço HTTPS da Netlify.

O index.html deve ficar na raiz, ao lado dos arquivos CSS, JavaScript e da pasta assets.

Para publicação manual na Netlify, envie a pasta extraída com index.html na raiz.
